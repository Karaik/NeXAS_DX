## 新版怎么选到想用的武装

- 默认A／B／C是键盘Z／X／C，D可用Shift、V或数字小键盘5；更改过键位时以「コンフィグ」为准。第一FC槽使用A+B；初始化器所在第二FC槽使用未按A时的B+C，仍需满足游戏本身的使用条件。
- 近距离与远距离是站立攻击的两组选择。要试远距招，先松开方向、保持合适距离；一边移动一边按同一个按钮，可能选到普通冲刺组。
- 要使用搜索冲刺组，先用D进入搜索冲刺状态，再用A／B／C。普通冲刺组用于方向移动／普通冲刺中的攻击选择；它不是“按住D的另一种名字”。先看实际动作和左侧装备名称，别只凭按下了哪个物理键判断出招。
- 新默认配置的12个普通槽都已填满。自行改装或读取旧存档留下空槽时，同一个按钮可能继续选到后续分组；空槽不一定等于不出招。
- 装备时先单击右侧要用的武装进入`CHANGE`，再单击左侧目标槽；核对左侧名称已改变，且右侧该武装显示`EQUIP`。鼠标悬停的预览只是演示。训练菜单「装備変更」可重新打开装备页；装备页`CLOSE`会进入训练。

每角默认表按**近距离、搜索冲刺、远距离、普通冲刺**排列，每行A／B／C共12个普通槽，再加第13槽FC与第14槽初始化器。54招均各占一个普通槽；没有把FC、初始化器或内部辅助动作当作追加名额。

下表热耗为新武装的配置值；射击创建次数不等于命中次数，两段攻击也不保证都打中。推荐箭头均明确列为**新包待实测候选**：能否连续压住同一目标，要看命中、距离、高度、取消时机和热量。发射后能换招只表示可以继续操作，不能据此说已经形成真连。

# BHE九角色DX改造包使用说明

当前为开发版说明。实机验收和最终发行包尚未完成；下表描述已写入资源的行为，不能当作游戏效果已经验收。

## 内容与兼容基线

重做Tsukuyomi、Yuri、Freja、Nagi、Misaki、Naoto、Katou、Wilhelm、Motoki；Sou沿用已有实现并保留在包内，不属于本轮角色重做。完整机体表需保留ID113，以兼容原配置中的选择和114行记录。

沿用DX原有的装备、热量和连段操作。新增变体与原武装同时保留，可以按打法选择；普通武装有12槽，另外各有一个FC和初始化器槽。部分武装较少的角色保留一个空普通槽。

兼容资源基线为本仓库`src/main/resources/bsdx_game`。构建EXE使用`src/main/resources/ida-reverse/BaldrSky.exe`，SHA256为`713cf605360a55a863f87bfbdea5453aaeeb2a33983ad4a005c9297e3a86e757`。游戏资源目录中的旧EXE带宽屏改动，会使装备预览镜头异常；安装时须使用本次生成的EXE。EXE与PAC必须来自同一份构建记录，不能混用以前生成的文件。

## 安装与恢复

1. 先关闭游戏，为现有游戏目录和存档保留可恢复副本。
2. 在一份独立的DX游戏目录中放入本次生成的`Update3.pac`，并将同次生成的EXE作为`BaldrSky.exe`使用。保留这份副本原来的EXE和同名补丁包备份。
3. 该副本中若已有其它来源的`Update3.pac`至`Update7.pac`，先移到备份目录；高优先级旧包可能覆盖本次资源。
4. 从该副本的`BaldrSky.exe`启动，点击「スタート」→「バルド地獄」→「機体選択」选择角色；「装備」设置武装，「練習」进入训练。默认键位见下文。
5. 恢复时关闭游戏，移走本次EXE/PAC，再还原备份。不要删除存档来排查问题。

旧存档可能保留原来的装备配置。新增武装可以在武装设置中按下表日文名称查找；更换角色或读取旧配置时，确认实际装备栏中的名称。不要把FC或初始化器装到普通武装槽。

Sou保留原有玩法实现，但玩家武装菜单必须遵守DX的0至152编号边界。当前包隐藏153至210共58个菜单条目，同时保留其MEK、动作、Material与AI数据；其中包含部分FC及编号174的Sou初始化器，它们不能从菜单装备。此前172154及更早包仍会在滚到越界条目时触发范围检查，不能作为通过验收的发行包。

## 默认操作

以下键位来自本基线的原版教程；旧存档或自定义配置可能改过键位，以「コンフィグ」中的实际设置为准。

| 操作 | 默认键盘 |
| --- | --- |
| 移动 | 方向键或数字小键盘 |
| A | Z |
| B | X |
| C | C |
| D | Shift、V、数字小键盘5任一 |
| 暂停 | Esc |
| 第一FC槽 | FC槽满时同时按A+B，即Z+X |
| 第二FC槽／本包初始化器 | FC槽满、未按A时同时按B+C，即X+C |

手柄按键以设置页面的A、B、C、D及START对应项为准，旧配置可能使用不同物理按钮。两个FC槽使用不同组合键；初始化器的本包操作依据当前引擎选择逻辑填写，实际效果仍待本包实机确认。

普通武装按近距离、搜索冲刺、远距离、普通冲刺分组，每组各使用A、B、C。普通冲刺会优先于近距离选择；测试站立远距离武装时，先松开方向键。当前分组没有可用武装时，引擎会沿同一按钮继续查找后续分组，顺序为近距离→搜索冲刺→远距离→普通冲刺；空格不一定让该按键没有动作。

训练相关菜单的说明文字可以用于定位功能：

| 日文说明文字 | 功能 |
| --- | --- |
| `初期位置に戻します` | 回到初始位置 |
| `装備を変更します` | 进入武装设置 |
| `敵機を変更します` | 更换训练敌机 |
| `マップを変更します` | 更换训练地图 |

进入武装设置后，按下表日文名称查找本包武装，并核对实际装备栏。鼠标移到武装上就可能开始演示；出现动画或日文简介，不表示已装备。更换武装时先单击左侧目标槽，再单击右侧武装，确认左槽名称已经改变。右键取消当前选择；不要用双击代替这两个步骤。

## 角色与武装

“默认入口”指本包预设，旧存档以实际装备栏为准。先处于对应攻击类型，再按A/B/C；第一FC槽用上文的A+B组合键。

| 角色 | 武装日文名称 | 默认入口 | 已写入的变化与用途 |
| --- | --- | --- | --- |
| Tsukuyomi | `袈裟・一閃` | 近距离A | 袈裟的踏入速度提高；38帧后进入納刀，再结束动作。适合一次接近后收刀重整距离。原袈裟保留拔刀后续连击路线。热耗12。 |
| Yuri | `アサシンダガー` | 搜索冲刺A | 刺入判定与原生命中派生窗口同步调整为44至50帧，基础攻击参数100→140，热耗28。 |
| Yuri | `サイドステップキック` | 搜索冲刺B | 侧移速度提高，原攻击参数80与恢复段保留。用于调整位置，热耗12。 |
| Freja | `スピア` | 搜索冲刺A | 两个突入分支的速度与基础攻击参数提高，攻击参数150→180，热耗24；该招与ラッシュ本身没有热量分支，不能把参数增强当作热循环。 |
| Freja | `武幻剛乱舞`（默认FC） | 第一FC槽 | 沿用原生热充能连击链：依据实际可用`CHARGE_FREE`预算继续连击或转入后段，原计数与消耗节点保留。`叛天轟瀑斧`仍可自行选装。低/高入口预算的实际打数、伤害及结束状态尚待实机对照。 |
| Nagi | `瞬間ディフレクト` | 近距离A | 防反受付缩为5至19帧；未成功时20帧解除装甲，39帧结束。成功后保留原生反击。适合短时读招，原长防御版仍可选。热耗12。 |
| Misaki | `転移手・挟撃` | 近距离A | 前方四条手/轨迹发射后，间隔12帧追加后方四条；动作窗口延长以容纳第二拍。可配合床召還、掴み压制。热耗36。 |
| Naoto | `ワンツー・コンファーム` | 近距离A | Jab在11至16帧命中才接现有ストレートパンチ，落空保留原37帧结束。用于轻拳确认后追击。热耗20。 |
| Katou | `トンファー・二連打` | 近距离A | 去除按键循环，两次打击各自完成后快速进入下一段，最后収納。原持续连打版保留。热耗18。 |
| Wilhelm | `交互砲撃・離脱` | 近距离C | 第二阶段右侧四条炮击晚8帧发射，左侧与中心保留原时间；50帧后进入終了并回四足形态。热耗40。 |
| Motoki | `集中爆撃・帰投` | 搜索冲刺C | 可从地面自行离陆，投下六枚炸弹后降落收招；准备期间会再次确认与目标的高度差，不足时继续升高，无法达到时不投弹归投。热耗40。固定甲靶预览已验证命中与着地，跨武装路线仍在验收。 |

帧数按游戏的动作帧计算；基础攻击参数不等于最终伤害，实际数值还受敌方状态与连段补正影响。追加的形态退出通过动作跳转完成，不等同于另外装备一次退出武装并获得其热量收益。

形态角色的默认装备保留进入与退出：Wilhelm的搜索冲刺A为`キャタピラ：開始`，搜索冲刺C为`キャタピラ：終了`；Motoki的搜索冲刺A为`飛行形態：開始`，普通冲刺A为`飛行形態：終了`。原飞行招式按各自条件使用；新`集中爆撃・帰投`自身会离陆，无需先另外使用`飛行形態：開始`。不要仅靠武装名称判断其它招式的前置状态已经满足。

Freja的`CHARGE_FREE`指该阶段实际可用的热充能（ヒートチャージ）预算，不能直接等同于出招前的普通热条`HEAT`。下文记录的`run_20261027_094119_577`已包含默认FC、武器说明、远距／普通冲刺预设修正及原有Sou。旧存档仍可能保留原FC或此前的分组配置，需核对武装名称并按正确分组重新设置。

第3行第5列是JINKI的柊 赤緒／モリビト２号。以上格位与名称已由最终资源核对，九个重做角色均已在游戏中选入并观察主要武装；这不代表各角色所有武装及连段已经验收。

选机后回到设置菜单，点击「装備」进入武装界面。右侧列表可找到「袈裟・一閃」等新增名称；按前述两次单击完成装备，再核对左侧槽中的名称。预览中双方机体、实际命中及部分形态收招已得到局部实测，全部武装仍在逐项验证。

装备界面底部点击`SETUP`会展开菜单；其中`機体選択`可以直接更换自机，已在多角色间实际验证。右键退出当前选择，上一项预览可能继续播放。点击装备页`CLOSE`会进入训练场；训练底栏的「装備変更」可再打开装备页。不要把关闭装备页误认为已经返回HELL设置。

## 构建与记录

在仓库根目录串行执行：

```powershell
mvn -q "-DargLine=-Xmx6g" "-Dtest=TestBheByJinkiRunner#testRunNineCharacterRework" test
```

每次生成独立的`target/bhe-playable-builds/run_*`目录；可加`"-Dbhe.playableBuildRoot=C:/NeXAS_DX_runs/builds"`改到指定输出盘。`build.json`记录实际EXE、PAC路径和SHA256；`target/bhe-playable-build-latest.json`指向最近成功生成的一轮。运行测试只用明确指定的类或方法，不执行默认全套资源测试。

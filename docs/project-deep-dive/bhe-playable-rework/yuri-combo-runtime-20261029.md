在默认modifier100及单逻辑步时，`5F8C10.c`以Graw/200扣Vz；G100相对G50会加倍向下加速度。它确实可能影响没有显式重力事件的后招，034中的W12已经读到继承。它也不是无条件污染所有动作：W11起手写10，W13起手50，W14起手0，都会覆盖原G；接地时不会持续产生向下位移。

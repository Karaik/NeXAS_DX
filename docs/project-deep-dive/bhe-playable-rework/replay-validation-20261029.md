## 工具边界

工具只接受明确template/out/input-json，输出已存在或覆盖模板时拒绝。严格校验三块长度、zlib EOF、文件EOF、8*N、帧上限和已知输入位；强制无输入收尾，前两块逐字节保全。真实格式验证及15项拒绝检查位于`target/bhe-audit-20261026/replay-input-fixture-20261029/verification.json`。

因保留metadata，槽列表时间仍显示原模板47.86秒，实际播放按第三块300帧在5秒停止。该工具为验收夹具，不把该旧metadata时间当作运行时长度或发行给玩家的录像说明。未知初始字段保持原样，不猜测修写。所有原存档、原录像及旧包保留。

# BHE 2026-10-29～30实机文本证据

本目录保存C盘工作目录删除前的文本证据。没有复制游戏程序、PAC、转储、截图、录像、存档、资源二进制或压缩包；没有运行构建或测试，没有修改C盘源文件。

- records/runtime：试跑事件和CDB日志、结束状态、输入身份清单、预览文本记录。
- records/builds、audits、delivery-candidates：已有构建身份、审计报告和说明文字。
- records/seeds、archives：种子与既有归档操作的文本清单；不含种子存档或恢复脚本。
- manifest.json：原路径、原始长度和SHA256、存储路径及存储文件SHA256。

## 读取与校验

records中的文件都是UTF-8无BOM、CRLF格式的JSON文本容器。encoding指定源文字编码，text保存原文件的完整文字。将text按encoding重新编码，必须得到manifest中source_sha256所指的原始字节。检查历史CDB日志的字节偏移时，应使用这一重建原文，不能使用JSON容器的文件偏移。

原有换行、BOM字符和控制字符保留在text字符串中；一个原CDB日志使用CP932，其他记录使用UTF-8。容器本身统一使用仓库要求的UTF-8无BOM和CRLF。所有文本均在复制后验证存储哈希和重建原文哈希。

## 证据边界

原路径只说明来源，不要求C盘目录继续存在，也不授权执行文本中记录的历史命令。本目录可保留当时观察到的出招、收尾与故障记录；由于不保存运行包、录像和存档，不能直接重放旧场景，也不保证旧运行环境完全重建。Sou全武装及新增54武装尚未完成的实机验收仍须后续进行。
